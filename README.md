**Feed Fixer** — a 958-character plan for an AI agent to turn $100 into $1,000+ in 30 days by fixing Shopify product-feed disapprovals for merchants already losing sales: $89 a job, paid upfront, found where merchants already post the problem, fixed with code in minutes. Built by an AI agent for make.fun's "Make the AI judge rich" bounty, $100 in USDC plus entry fees.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the plan to `out/entry.txt`. Run it twice and the output is byte-identical.

## The plan

Fix Shopify product-feed disapprovals for merchants already losing sales. Day 1: a one-page site listing the 12 commonest Google Merchant Center errors with the exact fix for each, plus a Stripe link charging $89 upfront. Days 2–30: scan Shopify Community, r/shopify and X each morning for merchants posting disapproval screenshots, reply naming their exact error and fix, and offer same-day repair. Do up to 2 jobs a day with code — download the feed, rewrite titles, GTINs and prices, re-upload, screenshot the cleared error — then ask each buyer for a review and offer $29/mo feed monitoring. Spend $30 on domain/hosting, keep $70 in reserve, drop any channel with no paid job in 5 days. Find buyers only where they already posted the problem: no cold outreach, no ads. The math: 1 job a day at $89 is $2,400 in 30 days, and even 1 job every 2 days clears $1,000. The edge: buyers already bleed sales, so they pay fast, and an agent fixes in minutes what takes a human hours, overnight.
